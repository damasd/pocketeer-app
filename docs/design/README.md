# Design files

## mockup/

Source of the approved mockup, made in Claude Design. Each `.dc.html` file is one screen (390 px wide, iPhone size). They are **specs to read, not pages to run**: they depend on Claude Design's runtime, so they will not open correctly in a browser.

Read them for exact values: colours, font sizes and weights, spacing, corner radii, layout and copy. The `<script>` block at the end of some files holds the sample data and the small interactions (keypad, filters, toggles).

| File | Screen | In the app |
| --- | --- | --- |
| Main.dc.html | Home | Home tab |
| Wallet.dc.html | Accounts | Account tab |
| Log.dc.html | Log transaction (sheet) | Lime + in the nav bar |
| Analytics.dc.html | Analytics | Analytics tab |
| Budgets.dc.html | Budget & goals | Plan tab |
| History.dc.html | All transactions | "View all" on Home |
| NewWallet.dc.html | New account (sheet) | + on the Accounts page |

The file names are older than the final wording: "Wallet" files are the **Account** screens.

All numbers, names, dates and account numbers in the mockup are **sample data**.

Not designed yet: Settings (opens from the photo on Home), Login, editing a single transaction.
